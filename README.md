# Veterinary Clinic System

Java client-server application for managing the operations of a veterinary clinic, developed as a university project at the Faculty of Organizational Sciences, University of Belgrade.

The system supports everyday clinic activities such as managing employees, animal owners, veterinary services and invoices.

## Key Features

- User authentication
- Management of employees
- Management of animal owners
- Management of veterinary services
- Invoice creation and management
- Client-server communication
- Relational database integration

## Project Structure

The application is divided into three modules:

- **VeterinarskaAmbulantaKlijent** – client application and user interface
- **VeterinarskaAmbulantaServer** – server-side application logic and database communication
- **VeterinarskaAmbulantaZajednicki** – shared domain and transfer objects used by both client and server

## Tech Stack

**Language:** Java  
**Architecture:** Client-Server  
**Database:** MySQL  
**Development Environment:** NetBeans

## About

The project was developed as part of the Software Design course at the Faculty of Organizational Sciences.
